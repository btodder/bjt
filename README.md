# bjt

An early skeleton of a personal architecture portfolio site for Brandon Todder.

**Live (GitHub Pages):** https://btodder.github.io/bjt/

## Contents

- `index.html`: page with a name header, a CSS grid layout (header / menu / main / right / footer placeholders), and nav buttons for Samples, About, Expertise, and Contact
- `todder.css`: styles for the grid and buttons

It's a static site with no build step. Open `index.html` in a browser to view it locally. Pushes to `master` publish to GitHub Pages.

## Status

Placeholder content only. The grid areas and buttons don't link anywhere yet.
